# NorthStar Trading Ltd — End-to-End Bookkeeping & Financial Reporting in Excel

An end-to-end simulated bookkeeping project built in Microsoft Excel for a fictional B2B technology equipment distributor.

The project demonstrates how raw business transactions can be processed through the accounting cycle, from **source transactions to final financial statements and closing entries**.

> **Portfolio project:** This is a fictional educational project and does not represent employment or client experience.

## Key Learning Outcomes

This project helped me connect ACCA accounting concepts with a practical spreadsheet workflow.

In particular, I focused on:

1. Maintaining the flow of information from transactions to financial statements.
2. Understanding how adjusting entries affect reported results.
3. Linking accounting schedules rather than preparing outputs independently.
4. Building spreadsheet controls to reduce calculation and classification errors.
5. Applying accounting concepts in a simulated business environment.

---

## Assumptions & Simplifications

This is an educational portfolio project, so several assumptions have intentionally been made.

Examples include:

- Income tax is based on a project assumption rather than an actual tax computation.
- The loan arrangement fee uses a simplified treatment; a complete IFRS 9 treatment would require consideration of transaction costs and the effective interest method.
- Bank transactions are recorded through a Bank account without a separate physical cash account.

These simplifications are documented so that the project is not presented as professional accounting advice or a production accounting system.
